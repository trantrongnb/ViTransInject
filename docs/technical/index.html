ViTransInject: Evaluating Translation-Mediated Indirect Prompt Injection in Vietnamese LLM Agents

Keywords
Indirect prompt injection · LLM agents · Vietnamese NLP · Multilingual safety · Machine translation

Abstract. Vietnamese LLM agents may normalize or translate untrusted content before processing, yet it remains unclear how such transformations affect susceptibility to indirect prompt injection. We present ViTransInject-Bench, a Vietnamese benchmark covering multiple agent tasks, linguistic representations, attack strategies, and translation-mediated deployment pipelines. We introduce the Translation Amplification Factor to quantify paired changes in attack success across linguistic representations, and evaluate a Cross-View Consistency Guard that compares agent behavior across original Vietnamese, diacritic-free Vietnamese, and English-translated views. Across five open-weight models, bilingual deployment reaches a mean ASR of 9.7%, compared with 7.1% under direct Vietnamese processing. Machine-translated and bilingual configurations obtain pooled TAF values of 1.30 and 1.27, although the direction and magnitude of these effects vary across models. The guard reduces mean ASR from 7.7% to 3.6% while producing fewer false positives on clean look-alike cases than keyword filtering, at the cost of additional agent inference.

01overview

LLM agents read emails, retrieved documents, customer records, and search results, and may act on them through tools. Untrusted content can carry instructions that redirect the agent from the user's task: task hijacking, unintended tool use, or information disclosure. Existing IPI benchmarks evaluate English settings almost exclusively.

In multilingual pipelines, content is often transformed before it reaches the agent. Vietnamese inputs may appear without diacritics, mixed with English, or machine-translated. ViTransInject studies the case where the injection is already embedded in a Vietnamese document and the language transformation is introduced by the deployment pipeline, not by the attacker.

02benchmark

Each task pairs a trusted request q with untrusted content c. The attacker may only insert a span s into c; it cannot touch the request or the system prompt. A pipeline P presents (q, c_atk) to agent A, which returns one ACTION (a structured tool call) or one ANSWER. Each case defines a machine-checkable predicate; the attack succeeds when the predicate holds. Tools are simulated and never executed.

03method

Deployment pipelines (all start from vi_full)

P1 vietnamese direct
document, request, and system prompt stay in Vietnamese
P2 full translation
document and request translated to English; English system prompt
P3 query-only
request translated to English; English system prompt; document stays Vietnamese
P4 bilingual context
Vietnamese document concatenated with its English translation; Vietnamese request and system prompt

Paired metrics

TAF_v = ASR_v / ASR_vi_full

Relative change in attack success versus original Vietnamese. > 1 amplifies, < 1 attenuates; undefined when the baseline is 0.

ΔASR_v = ASR_v − ASR_vi_full

Absolute change, reported because a ratio can look large on a small baseline.

Flip_v = |{i : y_i(vi_full)=0 ∧ y_i(v)=1}| / |I_v|

Share of paired attack cases that fail under vi_full but succeed under representation v.

04results

RQ1 · attack success across deployment pipelines

No pipeline produces a consistent effect across all models. Mean ASR rises from 0.071 under P1 to 0.097 under P4, driven mainly by Qwen2.5-3B and Sailor2-1B. Query-only translation is highest for Qwen2.5-1.5B; Gemma-2-2B stays flat or slightly lower under translation-mediated pipelines.

RQ2 · effects of linguistic representations

Cross-lingual configurations produce the largest pooled increases. mt_en and bilingual raise pooled ASR from 0.071 to 0.092 and 0.090 (TAF 1.30 and 1.27), increase ASR for four of five models, and yield the highest flip rates. Teencode has the lowest pooled ASR and never increases attack success. Model-level effects are heterogeneous: bilingual gives TAF 2.33 for Llama-3.2-1B and 0.60 for Qwen2.5-3B.

05defense · cross-view consistency guard

1 · viewsvi_full · vi_nodiacritic · mt_en

Same task, model, tools, and decoding. Vietnamese system prompt for the two Vietnamese views; English for the translated view.

2 · signaturesig(a) = ANSWER | tool:target

Deterministic per view. target is the normalized security-relevant argument, e.g. the lowercase recipient of send_email.

3 · decisionz1 = z2 = z3 → allow
otherwise → block

Compares actions, not wording. Three agent passes per case. Misses attacks that stay text-only in every view.

RQ3 · effectiveness and utility trade-offs

The guard reaches the lowest mean residual ASR and is best for Llama-3.2-1B, Qwen2.5-1.5B, and Gemma-2-2B; keyword filtering is lower for Qwen2.5-3B and Sailor2-1B but blocks every clean look-alike case. Spotlighting keeps the most benign utility with no blocking false positives, but reduces attack success less.
